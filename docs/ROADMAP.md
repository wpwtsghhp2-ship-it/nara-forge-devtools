# Roadmap

## Current (v0.1.0 development)
- Standalone Node.js release-manifest verifier
- Fail-closed behavior for missing, stale, inconsistent, or failing test evidence
- Example manifest and local test suite
- GitHub Actions test workflow (hosted CI verdict must be independently checked)

## Next
- Verify hosted CI and tag the first release after success
- Validate evidence authenticity rather than only checking supplied metadata
- Publish third-party CI integration instructions and JSON schema
- Invite and review real community contributions

This roadmap is not a promise of delivery dates or existing community adoption.
